## 关键修复

- 正常试卷和做题模式不再显示听力题干；听力题干只由音频朗读。
- 普通试卷视图不再显示听力原文/transcript；仅答案解析视图显示。
- 分页估算同步排除隐藏的听力题干，避免题干隐藏后产生大块空白。
- 新增听力纸面可见性回归测试，锁定 Project_04 旧规则：
  “听力只印选项 A–D 与题号，题干由音频朗读”。

## 根因

旧规则已写明听力只印选项和题号，但试卷渲染层一直无条件渲染题干，并且在教师普通视图显示了听力原文。生成数据和音频计划没有错；遗漏的是渲染与分页层核对。
