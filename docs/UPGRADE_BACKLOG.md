# 六级智卷后续升级清单

## 自动更新推送

状态：已记录，暂不实现。

目标不是简单地下载并运行一个远程 EXE，而是建立可验证、可回滚的 Windows 更新链：

1. 使用独立更新清单，包含版本号、最低可升级版本、下载地址、SHA-256、文件大小、
   发布日期和更新说明。
2. 更新清单必须带数字签名；安装包也必须做代码签名，客户端只接受签名和哈希都通过的文件。
3. 默认先提示用户，由用户确认后下载；下载完成再次核对哈希，再交给安装器。
4. 生成试卷、导出 PDF 或合成音频期间不得静默重启。
5. 保留上一版安装包和回滚入口；升级失败时恢复原版本，不触碰用户数据目录。
6. 更新服务不可用时必须静默降级，不能阻断离线使用和现有功能。
7. 首次上线前需要确定二进制托管位置、签名证书、发布回滚流程和隐私说明。

当前版本只保留手工安装升级，不访问远程更新地址。
