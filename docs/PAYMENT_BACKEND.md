# 赞赏方案与未来动态码契约

## 当前决定

当前使用爱发电创作者支持页：

```text
https://afdian.com/a/tobeatian
```

- 六级智卷只打开外部 HTTPS 支持页面；
- 软件不展示个人静态收款码；
- 软件不保存支付信息，也不需要商户号或支付后端；
- 所有功能保持免费，赞赏不会解锁或限制功能。

开发构建可在“设置 → 通用 → 支持作者”填写爱发电地址。正式构建通过
`VITE_SUPPORT_PAGE_URL` 注入固定页面地址，例如：

```dotenv
VITE_SUPPORT_PAGE_URL=https://afdian.com/a/your-page
```

## 为什么暂不做微信动态码

微信支付 Native 动态订单码需要微信支付普通商户号。普通商户号需要营业执照等主体资料，
只有个人身份证无法注册。个人静态收款码不能作为软件远程经营或持续赞赏的合规替代。

## 未来切换微信 Native 的前置条件

1. 注册企业或个体工商户并取得营业执照。
2. 申请微信支付普通商户号。
3. 开通 Native 支付并绑定 AppID。
4. 准备商户 API 证书、API v3 Key、平台证书。
5. 部署持续在线的 HTTPS 后端，用于创建订单、接收并验签回调、查询订单状态。
6. 由实际经营主体补齐退款、客服、税务、用户协议和隐私说明。

客户端不得保存商户私钥、API v3 Key 或平台证书。服务端必须验证微信回调签名、金额、
商户号、应用 ID 和订单号，并做到回调幂等。
