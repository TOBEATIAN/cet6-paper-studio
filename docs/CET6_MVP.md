# 六级智卷 MVP 规格

## 产品边界

第一阶段只做 Windows 本地单套生成：

1. 用户填写自己的 DeepSeek API Key。
2. 按选题蓝图、写作、听力 A/B/C、阅读 A/B/C、翻译九个阶段生成一套固定结构的六级模拟卷。
3. 每完成一个阶段就写入本地断点，重新发起时跳过已完成阶段。
4. 最终合并并通过结构校验后，先预览再应用到本地试卷。
5. 在本地编辑和预览，并导出答案解析版、仅试题版。
6. 自动听力 MP3 已接入；结构、难度、答案对齐等确定性质检已接入生成硬闸门。

## 2026-10-29 第二轮反馈

- DeepSeek 官方 Search / Fetch 已接入联网搜索配置，并复用模型 Key。
- AI 智能体只保留六级命题角色。
- 对外文案不再使用“教师版/学生版”，改为“视图/预览”和“答案解析/仅试题”。
- 手工添加题目时只显示八个六级板块。
- 新增答案导入与复盘记录。
- 移除班级字段。
- 生成内容的中文解析为硬闸门。
- 默认试卷名使用年月日。
- 参照 2026-09-26 后的成卷调整单选列布置、Part/Section 标题、页边距和页脚。
- 翻译支持 1-3 个中文词的英文提示。

## 2026-10-30 复盘导入

- Word 文件使用 Mammoth 提取正文，旧版 `.doc` 需先另存为 `.docx`。
- 手写作文、翻译或客观题答案可一次选择多张 JPG、PNG、WebP、GIF 图片，直接发送给
  当前配置的视觉模型做忠实转写；识别文本先进入可编辑文本框，确认后才应用。
- 客观题默认按正确计算，用户只标记错题；复盘记录只保存显式错误答案，不再把全部
  正确选项重复写入。
- 复盘与质检弹窗都增加了错误兜底；即使内容渲染失败，也可以返回工作台，不会整窗黑屏。

## 2026-10-30 排版收口

- 默认版式改为 A4、窄边距、10.5pt Times New Roman，中文使用宋体回退，与现有
  9 页模拟卷和真题更接近。
- 写作与听力不再在试卷正文预留学生作答区，避免 Part I 和 Part II 被空白推成两页。
- 听力按 Conversation One/Two、Passage One/Two、Recording One/Two/Three
  分组，每组显示自己的题号范围。
- 阅读 A 的词库放在文章后，26-35 空位使用可见下划线；阅读 B 的 36-45
  连续输出；阅读 C 按 Passage One/Two 分组，段落使用首行缩进。
- 同题组内部使用紧凑间距；分页允许后续题块回填上一页剩余空间，优先消除大块空白。
