# 六级智卷 0.4.0

## 新功能

- 专项训练：可从八个 CET-6 板块中任选一个或多个生成独立训练卷。
- 专项卷保留正式题号与分项分值，只执行所选板块的提示词、质检和听力合成。
- PDF/图片真题导入：生成可编辑结构化草稿，支持完整套卷或单板块。
- 阅读 C 跨套拼合：显示题号重排为 46–55，内部保留原套次与原题号。
- 答案自动检索：复用 DeepSeek Search/Fetch、Tavily、Exa 或 Firecrawl，
  显示来源、证据及冲突状态，未人工确认前不参与评分。
- 本地答案库：联网或人工确认后的答案自动入库，下次先查本地库；
  支持 JSON 导入导出，阅读 C 按文章签名和原题号分别匹配。
- 完整导入真题 130 分钟计时；板块导入默认不限时，可手动开启。

## 听力

- B/C 五篇正文按女、男、女、男、女轮换。
- 每篇的标题、选题播报和题干使用与正文相反的音色。
- B/C-only 专项音频使用正确 Section 开场。
- 默认考试语速由 170 调整为 165 wpm；旧配置中的 170/175 自动迁移。

## 验证

- TypeScript 类型检查通过。
- 前端全量测试通过。
- Rust 38 项常规测试通过，6 项联网慢测按设计忽略。
- 生产构建通过；PDF.js 独立代码分包，worker 正确进入构建载荷。

## 边界

- 本轮未生成 NSIS 安装包。
- 真题正文、答案和录音不随安装包分发。
- 答案库架构支持未来随包提供权利明确的答案数据；不会自动打包第三方抓取汇编。
- 作业帮等私有或逆向拍照搜题接口未接入。
