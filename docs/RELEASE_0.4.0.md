# 六级智卷 0.4.0

## 新功能

- 专项训练：可从八个 CET-6 板块中任选一个或多个生成独立训练卷。
- 专项卷保留正式题号与分项分值，只执行所选板块的提示词、质检和听力合成。
- PDF/图片真题导入：生成可编辑结构化草稿，支持完整套卷或单板块。
- 同一次考试的三套真题 PDF 会按“第一套/第二套/第三套”页边界自动拆成
  三张独立导入卡，可逐套启停、修改页范围、重试或批量导入。
- 文本层完整的 PDF 直接读取文字，不运行 OCR；扫描版 PDF 才调用随包
  PaddleOCR Mobile，并缓存逐页识别结果。
- 阅读 C 跨套拼合：显示题号重排为 46–55，内部保留原套次与原题号。
- 答案自动检索：复用 DeepSeek Search/Fetch、Tavily、Exa 或 Firecrawl，
  显示来源、证据及冲突状态，未人工确认前不参与评分。
- 本地答案库：联网或人工确认后的答案自动入库，下次先查本地库；
  支持 JSON 导入导出，阅读 C 按文章签名和原题号分别匹配。
- 完整导入真题 130 分钟计时；板块导入默认不限时，可手动开启。
- 试卷库升级为带类型、套次、板块、考试年月、来源哈希和归档状态的索引，
  支持分类筛选、搜索、排序、多选归档与恢复。

## 专项训练

- 每个所选板块使用独立主题；阅读 C 的 Passage One/Two 分别填写主题。
- 空白主题分别随机，不再让同一次多板块训练共用一个总主题。
- 在非空试卷上发起专项训练时，先保存当前卷，再自动新建并切换到训练卷。
- 专项卷标题包含日期、板块和主题，便于在试卷库中定位。
- Reading C 两篇正文和两组五题并行生成；失败时只重修对应五题组。
- 固定答案字母与模型输出不一致时，程序自动移动正确选项并同步解析，不再整组重跑。

## 三套真题与答案页

- 一次可选多份听力音频，并逐套分配；两音频三套时会自动把第三套保留为无听力。
- 官方试卷明确省略 Listening 时，不再判为缺少板块。
- “答案速查/参考答案”页先独立识别并移出题纸范围，再按套填入答案表。
- 卷内答案优先于旧答案库和联网结果，Reading A/B 支持 A-O 及 OCR 的 `0/1` 混淆。
- 没有卷内答案时，搜索查询新增“考试年月 + 套次 + 六级真题答案”的通用入口。
- Reading A 的共享 A-O 词库同时兼容块级 `optionBank`、`wordBank` 和旧草稿首题
  `options`；建卷前自动复制到 Q26-Q35，不再误报选择题选项不完整。
- 导入阅读 A 的裸题号空位（如 `26`）可直接在横线中填写 A-O；现有已导入试卷无需重建。
- Reading C 先固定并持久化两篇正文，再分别生成 Q46-50、Q51-55；后续只做题目组内修复。
- Reading C 质量修复细化到单题：每题只收到自己的错误和冻结正文，修正后原位替换；
  具名观点题支持 `What/How/Why ... Dr. Name ...` 形式。
- 非流式模型请求遇到连接中断、响应体解码失败或 5xx 时自动退避重试；
  401/403、429 与正常超时不重试。

## 听力

- B/C 五篇正文按女、男、女、男、女轮换。
- 每篇的标题、选题播报和题干使用与正文相反的音色。
- B/C-only 专项音频使用正确 Section 开场。
- 默认考试语速由 170 调整为 165 wpm；旧配置中的 170/175 自动迁移。

## 验证

- TypeScript 类型检查通过。
- 前端 63 个测试文件 / 425 项测试全部通过。
- Rust 48 项测试中 42 项常规测试通过，6 项联网/慢测按设计忽略；
  `cargo check` 与 `cargo fmt --check` 通过。
- 生产构建通过；PDF.js 独立代码分包，worker 正确进入构建载荷。
- Tauri debug 编译通过，实际启动窗口标题为“六级智卷”且进程正常响应。
- 打包后的 `paddle-ocr.exe` 已实测中文试卷：2025 年 6 月第一套标题、
  作文与听力题干均可正常识别；第 1/9/17/23 页分别识别出三套边界和整份答案速查。
- 扫描版 23 页三套真题在当前 CPU 环境约需 9–10 分钟完成 OCR；
  带文本层的普通 PDF 不进入这条慢路径。
- 真实 OCR 答案页恢复三套共 140 个客观答案，Reading A/B 的 A-O 与 `I/O` OCR 混淆已覆盖。

## 边界

- 本轮未生成 NSIS 安装包。
- 真题正文、答案和录音不随安装包分发。
- 答案库架构支持未来随包提供权利明确的答案数据；不会自动打包第三方抓取汇编。
- 作业帮等私有或逆向拍照搜题接口未接入。
- PaddleOCR 单文件约 345 MB，外加约 21 MB 检测/识别模型；安装包体积会相应增加。
