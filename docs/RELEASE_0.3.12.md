- 荧光笔改为 PDF 式独立批注层，不再改写题目 Markdown。
- 长选区跨多个渲染节点时可稳定高亮，不再依赖修改试卷正文。
- 橡皮擦一次删除选区覆盖的全部高亮区间。
- 格式写回增加正文不变式保护，任何会改动可见文字的格式操作都会被拒绝。
- 恢复此前被误删的作文题干与 Reading B 正文。
- 微信和支付宝收款码独立配置、并排显示、各自支持放大。
- 收款码通过 Rust 后端读取字节并生成 Blob URL，不再出现本地资源权限加载失败。
- 正式安装版隐藏“支持作者”配置与上传入口，普通用户无法从界面替换赞赏码。
- JSON 保存继续保留最后有效备份，并在主文件损坏时自动回读。
