## 主要修复

- 做题模式下题目批注按钮不再覆盖正文，文本会自动避让。
- 跨段落、跨块长选区会拆成多个独立批注区间，荧光笔和橡皮擦均可处理。
- 批注新增源文本哈希，正文变化后不会把旧偏移贴到新文字上。
- 作答、批注和笔记写入数据目录的 `practice` 子目录，并保留本地缓存兼容旧数据。
- Reading B 通过 13 段正文后立即保存子检查点，第二次调用失败不会丢掉正文。
- `.bak` 恢复前会保留损坏文件现场；检查点读取统一走恢复逻辑，并提供重置进度入口。
- 听力播放器不再因点击试卷而卸载停播，新增 0.75× 至 1.5× 播放倍速。
- 云端 TTS 缺 Key 或调用失败时自动降级到随包 Kitten，并显示具体技术诊断。
- 微信、支付宝收款码作为内置资源打包，正式版仍隐藏上传/替换入口。
- 默认选择题创建为四个选项，批注模式不再提供“无色”，做题模式禁用正文格式改写。
- 深评返回必须包含 0–8 栏目与 D+1/3/7/16/35 复扫日期；阅读 C 未完成文章层时不能直接深评。
