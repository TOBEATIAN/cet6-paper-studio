# 写作引号与旧版复盘流程修复

日期：2026-11-01

## 写作给定句

### 根因

Project_04 的操作手册明确要求写作指令包含**全角引号的给定句**，但桌面端生成提示
只写了 `quoted opening sentence`。模型因此返回了普通 ASCII 双引号
`"..."`，在中文试卷中不符合旧流程排版。

### 修复

- 生成提示要求使用旧版固定模板：
  `For this part ... begins with the sentence “...” You can make comments ...`
- 解析 `parseCet6Stage` 时自动把 ASCII 引号规范为全角 `“...”`，并还原旧版模板。
- `buildCet6Paper` 标准化阶段再次兜底，历史阶段数据进入整卷时也会被规范。
- `auditCet6Stage` / `auditCet6Paper` 新增硬闸门：
  `writing:given-quotes`，没有全角双引号即报错。
- 对照旧版 `2026-10-27` PDF 后，标题恢复 `Part I　Writing　(30 minutes)`，不显示
  题号；给定句内嵌在旧版固定说明段中，不再添加 `Directions:` 或
  `Opening sentence:` 标签；新增 `writing:prompt-template` 硬校验。
- 当前 `paperId=eb32c436-372b-40f6-8f54-ad4a9b6ac830` 的写作题干与两份 Markdown
  已同步修正，重新审计为 0 error。

### 软件内看不到的原因

应用的 `bootstrap.json` 实际指向
`C:\Users\TOBEATIAN\Documents\AI试卷`，其中只有一份 0 题空白工作卷；修复后的
57 题试卷位于 `E:\Download\CET-6`。因此文件虽然已修，软件启动后并没有读取它。

已将当前用户和打包运行时的两个 bootstrap 指针都切回
`E:\Download\CET-6`，并实际启动新包核验：窗口标题与试卷标题正确，
Writing 区显示旧版标题、固定说明段和清晰的全角引号。

## 旧版四层复盘

### 新流程

复盘页新增“Project_04 四层深度复盘”：

1. **事实**：按标准答案和题号自动计分，列出标记错题。
2. **归因**：把学生所选选项、标准答案、题目解析和对应原文一起交给模型；必须使用
   Project_04 的错型库命名，不能只写“粗心”。
3. **模式**：读取历史复盘中的错型、写作分、翻译分和总分，检查连续套次及上次处方
   是否奏效。
4. **动作**：强制使用肯定动作，并带次数、时间或数量阈值。

附加流程：

- 写作与翻译按官方五档总体印象法先定档、再定档内分，逐句分类只作诊断。
- 升级稿必须以学生原文为底稿，并单独评分，写明“离下一档差什么”。
- 阅读 C 增加“先自己拆，再用 AI 对”：学生先写生词、长难句主干/修饰、段落角色；
  留空时 AI 只给待完成清单，不代写。
- 生成 D+1 / D+3 / D+7 / D+16 / D+35 间隔复扫日历。
- 用户可填写“复盘补充”，记录当时很确定、犹豫、蒙对或没听到的题，模型不得替用户
  编造听感。

### 兼容性

- 旧复盘记录缺少新字段时，由 Zod defaults 自动补齐，不需要迁移或删除。
- 深度复盘 Markdown、写作分、翻译分、总分和错型摘要会随复盘记录保存。
- 原有“一键修改稿”也改为同一套官方评分与升级稿规则，避免两套标准。
