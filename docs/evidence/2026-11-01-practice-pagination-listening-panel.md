# 2026-11-01 做题与听力界面热修

## 用户现场

- 听力面板只显示一部分，导出和软件内播放容易混在一起。
- 做题模式第 1 题只显示 A、B 两个选项。
- Reading A 只能在正文外选择，不能直接在 26–35 横线上填写 A–O。
- 作文、翻译需要图片识别导入。
- 做题模式错误显示听力原文，翻译阶段会提前。
- 需要多种颜色的荧光笔标注题干和阅读正文。

## 根因

1. 听力按钮位于左侧，但弹层仍以 `right-0` 展开，窄窗口下向左溢出。
2. 做题模式增加了选项按钮高度，分页需要按真实内容区重新测量。
3. 第一次真实高度测量读取了隐藏测量页中“会被全部内容撑高”的内容容器，
   不是固定单页可用高度，导致翻译块提前。
4. 听力原文有两条渲染路径：章节块和题目块；只隐藏章节块仍会从题目块泄漏。
5. Reading A 正文由 Markdown 静态渲染，没有把编号空位绑定到客观题答案。
6. 高亮选择原先只认定题干源，阅读正文没有可回写的 Markdown 源标记。

## 修复

- 听力弹层左对齐并限制为 `min(22rem, 100vw - 2rem)`；普通导出保持独立右对齐菜单。
- 隐藏测量页固定为单页纸高，再从固定内容区读取真实可用高度。
- 做题模式隐藏 CET 听力题目块原文；编辑和答案解析态保留。
- Reading A 的 `++26++` 等占位直接替换为 A–O 单字母输入框，并写入做题答案。
- 作文/翻译增加图片选择与视觉模型转写，结果回填后由用户核对。
- 进入做题模式自动打开“标记”工具栏；题干与阅读正文都可使用六色荧光笔。
