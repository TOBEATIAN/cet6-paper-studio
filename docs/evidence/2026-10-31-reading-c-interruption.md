# 2026-10-31 Reading C 仔细阅读中断修复

## 用户现场

`0.3.1` 在当前 `7/9` 断点上生成 Reading C 时被质量闸门拦截：

- 解析不满足“中文、英文依据、正确字母”三项；
- 第一篇最长句 52 词，但 12 词以内短句 11 句，超过上限 10；
- 两篇 8 字母以上词比例 19.8% / 15.2%，低于 20%；
- 10 题题型字段全部为空；
- 两篇素材来源字段为空；
- 正确项与最强支撑句的平均词重合率 50%，超过 40%；
- 正确项最长连续原文为 2,2,1,4,2,5,1,5,1,4 词，超过阈值的题数过多；
- 没有任何一道题询问具名人物或机构观点。

## 根因

原实现让一次模型回复同时生成两篇 430-450 词文章、十道题、选项、解析、
题型、来源和答案分布。约束过多，模型会漏掉可选字段，并优先完成正文而牺牲
句子节奏、词汇难度和改写强度。另有 `deepseek-flash` 隐藏推理耗尽输出预算的问题。

## 修复

按既有 Project_04 成卷流程拆分：

1. 两篇正文分别生成并分别验收，不再和十道题共用一次输出。
2. 程序固定题型分布为真题窗口：细节 6-8、推断 1-3、态度 0-1；当前计划含
   6/3/1、7/2/1、8/1/1 三种种子轮换。
3. 程序固定十题答案分布为 A2/B3/C3/D2，并保证每篇内部有变化。
4. 程序注入 `questionKind`、`source{outlet,type,topic}`、题号、题组和分值；
   不再依赖模型记得这些内部字段。
5. 两篇 source.type 自动取不同的两个类别。
6. 正文目标为：约 450 词、8/9 两个不同段数、至少两个短段、最后一段至少
   100 词、一个 55-65 词长句、5 个短句、25%-26% 长词、至少 12 个具体信息。
7. 题目的正确项要求跨句同义改写、不得连续照抄 3 词以上；解析明确排除
   三个干扰项并标注错因类型。
8. Reading B/C 重阶段统一把安全输出上限提高到 65,536 token；这不是强制消耗，
   实际仍按推理和正文 token 计费。

## 与旧成卷流程的对账

保留：

- 两篇各 430-450 词、6-12 段且篇间段数不同；
- 细节 6-8 / 推断 1-3 / 态度 0-1 / 主旨与词义 0；
- 段落 σ、长句、短句、长词、具体信息；
- 支撑句重合 ≤40%、最长连续照抄 ≤3 词且超限题 ≤2；
- 中文逐项错因、英文引述、正确字母；
- 至少一题问具名人物或机构观点；
- source 记录且两篇 type 不同；
- 听力仍采用最近成功成卷口径：A 360-400、B 310-365、C 合计 1300-1450；
- 听力选项均值、长度差、最长正确项、模板题干和强同形干扰项均升级为硬闸门。

不照搬：

- 早期手册中 A 280-320 / B 240-260 / C 1150-1250 的过渡口径；最近第 23-28 套
  实际成功卷均使用更长的现行窗口。
- 每套正文完全由人工微调的流程；桌面端改为固定结构 + 自动质量门。

## 2026-10-31 整卷复核补丁

用户指出命题规范适用于整张卷，因此本轮又把写作、听力、阅读 A/B/C、翻译逐项与
Project_04 操作手册、`qa_check.js` 和最近成功批次对账，不再只修 Reading C。

### 写作

- 程序按试卷种子从 8 类真题开头型式中选择，并验证生成句的实际开头型式。
- 生成前读取最近 4 份已完成试卷：相邻两套不得同型，同一型式在最近五套内
  不得超过 2 次。
- 继续硬校验 16-25 词、长词 26%-66%、陈述句、无 `whether`、
  无“机构＋should/must＋具体措施”、真题 Directions、中文思路和评分标准。

### 听力

- 保留 A 360-400、B 310-365、C 每篇 400-500 且合计 1300-1450 词。
- 新增每篇 A 长对话必须有 `Woman:` 与 `Man:` 双声。
- 整卷新增脚本长词率 ≥15%、题干长词率 ≥16%、题干平均 ≥10 词硬闸门。
- 25 题统一重排为 A6/B6/C6/D7；跨 A/B/C 边界也避免连续三道同字母。
- 正确项最长 ≤6/25、长度差 ≤6、强同形干扰 ≤4/25、模板题干 ≤4/25，
  选项移动后解析中的 A)-D) 与“故选 X”同步重映射。

### 阅读 A

- 26-35 的十个答案由程序按试卷种子从 A-O 中选十个不同位置，并满足回头、
  递增对 ≤5、无连续三项递增。
- 新增正文空格必须按 26-35 阅读顺序各出现一次、15 个词性必须是 `n/v/adj/adv`。
- 保留正文 260-300 词、词库 15 项、长词 ≥10/15、平均字母 ≥8.5。

### 阅读 B

- 13 段 A-M 单独生成，10 条陈述单独生成。
- 固定取 10 个不同段落，留 3 个干扰段。
- 程序按“试卷 ID + 标题 + 主题”重排最终题序，保证回头、递增对 ≤5、
  无连续三项递增；同卷重试稳定。
- 保留全文 1150-1250 词、直接引语 ≥6、引号 ≥9、引语归属、
  观点归属句、逐条重合 ≤69%、中位 ≤45%。

### 阅读 C

- 新增每题 `para` 依据段号：第一套 2/3/5/6/8，第二套 1/3/5/7/9，
  同篇内必须顺读。
- 新增旧版干扰项锚点规则：依据段及相邻段内，每题至少两个干扰项有具体锚点，
  例外最多 4/10。
- 新增四选项均值 ≥9 词的长选项题至少 4/10。
- 修正第二篇段落骨架：旧目标自身 σ 仅约 25.9，会必然被 26 的下限拒绝；
  新骨架仍合计 450 词，σ 约 26.7。
- 增加生成提示中遗漏的两条约束：“每题至少一个干扰项不短于正确项”和
  “至少 4/10 题使用 9-10 词长选项组合”。

### 翻译

- 原文保持 170-190 汉字、6-8 句。
- 参考译文最低要求由 50 词提高到 100 词，目标提示为 100-180 词。
- 行内英文提示恢复旧规范的 0-3 条，不再强制每篇必须有生词；若有，中文词必须
  出现在原文中且词条互不包含。
- 生成提示要求至少一个四字格/固定表达，以及至少一个无主句或双动作句。

### 指标口径修复

桌面端的“可定位具体信息”计数最初只覆盖阿拉伯数字、少量机构后缀和句首专名，
会漏掉英文数词及句中的人名/机构。现已按 Project_04 `lib/specifics.js` 补齐为：

- 年份、阿拉伯数字/百分比、英文数词；
- 大写机构后缀、段落内的单个或双词专名；
- 全部去重计数。

同一组旧流程自测样例在桌面端得到 `8 / 0 / 1`，与原实现一致。
