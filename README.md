# 六级智卷

本地优先的 Windows 六级模拟卷生成与质检工具。用户自行配置 DeepSeek API Key，软件负责按固定题型结构生成、编辑、预览和打印试卷。

## 当前 MVP 能力

- DeepSeek 默认预设：`https://api.deepseek.com` / `deepseek-flash`
- 默认使用 DeepSeek 官方 Search / Fetch，并复用当前模型 API Key
- OpenAI 兼容接口，模型名和 Base URL 可修改
- API Key 存入操作系统凭据库，不写入工程配置
- 仅保留“六级整卷命题专家”，不再显示数学、语文等未实现角色
- 按“选题蓝图 → 8 个题型板块”分段生成，避免单次输出整卷被截断
- 每完成一个阶段即写入本地断点，失败后可继续生成
- 生成失败直接显示失败阶段、后端原因、具体质检项和可复制的诊断信息
- 主界面统一为个人试卷工作区，不再提供教师/学生身份切换；答案与解析默认折叠
- 新增“做题”模式：可直接选择客观题、填写作文与翻译、提交客观题得分并带入复盘
- 最终执行 57 题、710 分、题号、题型、选项、解析与听力原文可见性的结构校验
- 质检报告覆盖篇幅、答案分布、中文解析、阅读题型、改写强度、正确项照搬等硬闸门
- 质检阈值、实词词表、支撑句和连续照搬口径以 Project_04 六级模拟卷的 `band_auto.json` / `qa_check.js` / `scripts/lib` 为单一标准
- 复盘中的客观题直接点选改错；写作、翻译分别在对应输入区导入手写作答图片，由当前配置的视觉模型转写
- 复盘直接复用 Project_04 旧流程：事实 → 逐项归因 → 跨套模式 → 带阈值的肯定动作；写作和翻译按官方五档总体印象法定档，阅读 C 坚持“先自己拆，再让 AI 核对”
- 客观题默认答对，只需修改错题；复盘记录仅保存用户明确标错的答案
- 语音设置提供阿里云、小米 MiMo、硅基流动、随包 Kitten 和自定义 OpenAI 兼容端点五类入口，地址、模型和男女音色都可编辑
- 听力目标语速设置范围为 140–200 词/分钟，默认 170
- 导出菜单可直接生成包含题干、7 条题组播报和 25 段 13.1 秒停顿的 `Listening.mp3`
- 自动生成音频默认与试卷一起写到 `papers/<标题>-<试卷ID>-Listening.mp3`；听力 A/B/C 完成后即可在后台开始合成
- 顶部“听力”面板可直接播放已有 MP3，支持暂停、前后 15 秒、拖动进度条和时间显示
- 顶部新增非强制“支持作者”入口，可配置赞赏码图片或支持链接
- 分句缓存支持失败续跑；所有引擎统一修剪静音、保持音高调速并编码 MP3
- 写作提供中文思路、中文评分标准，以及 150–220 词且沿用给定开头句的英文参考范文；用户完成作文后仍可在复盘中生成改写稿
- 写作给定句强制使用全角中文双引号 `“…”` 标注；模型返回普通 ASCII 引号时，解析和构建会自动规范
- 翻译提供中文难词英文提示
- 设置可选择关闭窗口时退出应用或留在系统托盘；生成中直接退出会先确认
- 生成进度显示已用时间、预计总时长和预计剩余时间
- 默认试卷名使用年月日，页面按真题风格使用 Times New Roman、窄边距、Part/Section 和完整页脚排版
- 听力按 Conversation / Passage / Recording 分组并显示各组题号范围
- 阅读 A 为文章、编号空位、A-O 词库；阅读 B 连续输出 36-45；阅读 C 按 Passage One/Two 分组并保留首行缩进
- 阅读 B 先生成 13 段 A-M 正文，再从 A-M 中选 10 个不同段落按段序写陈述，最后按试卷种子重排提问顺序
- 阅读 C 按“正文 1 → 五题 1 → 正文 2 → 五题 2”分步生成，题型、答案和来源元数据由程序定标
- 同页题目使用紧凑间距，分页时优先回填上一页剩余空间，避免大面积空白
- 右侧 AI 助手预填完整六级卷规格，也保留自由对话编辑能力
- 支持写作、听力 A/B/C、阅读 A/B/C、翻译八个部分
- 完整视图显示答案与解析，“仅试题”版本隐藏答案
- “仅试题”版本隐藏听力原文
- 本地 JSON 试卷库、自动保存、完整视图与试题预览
- JSON 导入导出、Markdown 导出和浏览器打印 PDF

## 使用

1. 第一次启动选择本地数据目录。
2. 打开设置，添加 DeepSeek 配置并填写自己的 API Key。
3. 点击右上角“生成六级整卷”，等待分段生成和结构校验完成。
4. 在右侧结果卡中预览并应用整卷；若中途失败，再次点击即可从已保存阶段继续。
5. 每道题点击“查看答案解析”展开答案和解析，默认不打断整卷显示。
6. 点击“做题”直接在软件内完成客观题、作文和翻译；提交后查看分数并进入复盘。
7. 点击顶部“听力”播放已有音频，或选择 140–200 wpm 重新生成。
8. 通过“更多 → 导出”打印 PDF、导出 Markdown 或 JSON。

## 合规边界

- 本工具是非官方辅助命题软件，不代表考试主办方。
- 不内置真题题目、真题答案、真题录音或官方标识。
- AI 生成内容必须人工复核并显著标识。
- 软件和生成物默认只用于个人学习；对外分发前另行确认出版、平台和版权要求。
